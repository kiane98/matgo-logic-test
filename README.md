# 🎴 고스톱 비동기 로직 및 시각 피드백 엔진 프로젝트

본 프로젝트는 웹 환경(HTML5 Canvas, JS)에서 복잡한 카드 게임의 비동기 상태 처리와 사용자 경험(UX) 향상을 위한 시각적 피드백 시스템을 연구하고 테스트하기 위해 제작되었습니다. 한국인에게 가장 친숙한 고스톱 룰을 예제로 채택하여 게임 알고리즘을 구현했습니다.

## 🎮 개발 테스트 버전 (Two Versions)

사용자의 환경에 맞게 로컬에서 실행할 수 있는 두 가지 프로토타입을 제공합니다.

### 1. mimmi matgo_joker ver.html
* **특징**: 보너스 패(2피, 3피 조커)가 포함된 현대적 룰 구현 테스트.
* **로직**: 보너스 패 획득 시 발생하는 이벤트 처리 및 상대방 데이터(피) 강탈 알고리즘 검토.

### 2. mimmi matgo_original ver.html
* **특징**: 조커 없이 48장의 화투 패만 사용하는 정통 맞고 알고리즘 테스트.
* **로직**: 순수 확률 분배와 가중치 기반 AI의 의사결정 수 싸움 구현.

## 🛠 주요 기술적 구현 사항

* **UI 타이밍 최적화**: '쪽', '따닥' 등 특정 매칭 시 발생하는 인지 부조화를 줄이기 위한 0.2초 마이크로 프리즈(Micro-Freeze) 기술 적용.
* **가중치 기반 AI**: 바닥 패와 손패의 가치(광·고도리·띠·쌍피·피)를 점수화해 패를 내고, 바닥에 같은 월 패가 2장이면 더 가치 있는 패를 가져갑니다.
* **AI의 고/스톱 판단**: 7점이 되면 무조건 스톱하지 않고 남은 패 수, 상대 점수·광·피 상황을 보고 고를 외칠지 결정합니다(최대 2고).
* **실시간 데이터 렌더링**: Canvas 위에서 점수 구성 항목(광, 피, 고도리 등)을 실시간으로 계산하여 툴팁 형태로 렌더링하는 시스템 구현.
* **입자 물리 시각화**: 점수 획득 및 '폭탄' 액션 시 80개 이상의 개별 파티클을 생성하고 물리 효과를 적용한 시각적 피드백 구현.
* **시간 기반 애니메이션**: 모니터 주사율(60/120/144Hz)과 관계없이 같은 속도로 움직이며, 카드 이동에 감속 효과와 폭탄·따닥·뻑 화면 흔들림을 적용했습니다.
* **웹 오디오 합성 사운드**: 카드 놓는 소리를 노이즈 기반으로 합성하고, 압축기(Compressor)로 소리가 겹쳐도 찢어지지 않게 했습니다. 소리 ON/OFF 설정은 브라우저에 기억됩니다.
* **반응형 레이아웃**: 모바일 폭에서도 화면이 잘리지 않습니다.

## 🔧 수정 이력

* 고 보너스(+1, +2점)가 고/스톱 판단 점수에 섞여 다음 턴마다 고 팝업이 다시 뜨던 문제 수정. 고 보너스는 최종 정산에만 반영합니다.
* 피박 판정이 카드 장수가 아닌 피 점수(쌍피 2점 포함) 기준으로 동작하도록 수정.
* 카드 섞기를 Fisher-Yates 방식으로 교체.
* 11월(오동)·12월(비) 그림 파일 순서를 월 순서(10 → 11 → 12)에 맞게 교체하고 코드의 예외 처리를 제거.
* 점선 영역(AI 패 자리)이 그려지지 않던 `roundRect` 덮어쓰기 문제 수정.
* 국진 이동 클릭이 애니메이션 도중 턴 처리 상태를 풀어 버리던 문제 수정.
* 폭탄 팝업의 "아니오" 버튼을 "흔들기"와 "그냥 내기"로 분리.
